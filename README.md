# CodeAlpha Data Analytics Internship - Amazon Review Analysis

Dataset: Amazon Fine Food Reviews (Kaggle, by SNAP). Random sample of 50,000 reviews from 568,454.

## Task 2: Exploratory Data Analysis
- Rating distribution, trends over time, review length analysis
- Hypothesis test: 1-star reviews are significantly longer than 5-star reviews (Mann-Whitney U, p < 0.05)
- Data issues: class imbalance, outliers, duplicates, partial year

## Tools
Python, pandas, matplotlib, seaborn, scipy

## Dataset
https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews
